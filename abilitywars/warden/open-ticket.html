Open Ticket

Opens a ticket in the given category. After running this command, a modal will pop up allowing the user to fill out the details of the ticket before it's opened.

If you want to create a message with a button that can be clicked to open a ticket, you can use the /create-ticket-button command.

Usage

  • /open <type: Ticket Type>

Parameter Details:

  • <type: Ticket Type> The type of ticket to open.
