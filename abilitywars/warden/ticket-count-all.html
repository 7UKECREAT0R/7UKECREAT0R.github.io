Ticket Count (all)

Counts the number of bans done by all staff members for the current/last pay period.

Usage

  • /ticketcount-all [lastweek: Boolean]

Parameter Details:

  • [lastweek: Boolean] If true, the count will be run for the last pay period instead of the current one. Defaults to False.
