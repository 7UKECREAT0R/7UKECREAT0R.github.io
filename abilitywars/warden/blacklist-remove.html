Blacklist Remove

Removes a blacklist from a user, allowing them to create a appeal or dispute again. Blacklists can either be applied on a per-roblox-user basis, or on a per-discord-account basis.

Usages

  • /appeal-blacklist-remove discord <user: Discord User>

  • /appeal-blacklist-remove roblox <user: Player>

Subcommand: discord

Removes a blacklist from a Discord user, allowing them to create a appeal or dispute again.

Usage

  • /appeal-blacklist-remove discord <user: Discord User>

Parameter Details:

  • <user: Discord User> The Discord user to remove the blacklist from.

Subcommand: roblox

Removes a blacklist from a Roblox user, allowing them to create a appeal or dispute again.

Usage

  • /appeal-blacklist-remove roblox <user: Player>

Parameter Details:

  • <user: Player> The Roblox user to remove the blacklist from.
