Set Punches

Sets the punch count for a given player. Must have in-game permissions to set punches. After running, the success message will show both the old and new punch counts.

Usage

  • /aw-setpunches <target: Player> <punches: Integer>

Parameter Details:

  • <target: Player> The player to set the punch count of.

  • <punches: Integer> Their new punch count.
