Manage Ticket

This is the master command for managing tickets. It has lots of subcommands, some of which require being executed inside a ticket channel to work. All the subcommands can only by run by staff members.

Usages

Ticket-Specific

  • /ticket blacklist [reason: Text]

  • /ticket close [reason: Text]

  • /ticket modify <property: Ticket Property> <value: Text>

  • /ticket nickname <name: Text>

  • /ticket top

Global (can be run anywhere)

  • /ticket cleanup

  • /ticket history <user: Discord User> [type-filter: Ticket Type]

  • /ticket history-by-closer <closer: Discord User> [type-filter: Ticket Type]

  • /ticket history-by-recent <limit: Integer>

  • /ticket recall <ticket-id: Integer>

Subcommand: blacklist

Blacklists the ticket's creator depending on the type of ticket. This does not close the ticket, it's simply a context-aware shortcut for the regular blacklisting process.

If the ticket is an appeal/dispute, the user will be blacklisted from creating future appeals/disputes. If the ticket was for a Roblox ban, they'll be blacklisted by Roblox user. If the ticket was for a Discord server ban, they'll be blacklisted by Discord user.

If the ticket is a player report, the user will be given the blacklist role and prevented from creating future reports.

Usage

  • /ticket blacklist [reason: Text]

Parameter Details:

  • [reason: Text] The reason for the blacklist.

Subcommand: close

Closes the ticket with an optional reason attached. This reason will be messaged to the user privately.

Usage

  • /ticket close [reason: Text]

Parameter Details:

  • [reason: Text] The reason for closing the ticket. This will be visible to the user.

Subcommand: modify

Modifies a property of the current ticket. The properties available depend on the type of ticket; Discord will generally show you all the available options automatically.

Properties aren't just values that can be changed, they can perform actions as well. More information about specific properties is available on the pages dedicated to each type of ticket.

Usage

  • /ticket modify <property: Ticket Property> <value: Text>

Parameter Details:

  • <property: Ticket Property> The property to modify. Dependent on the current ticket type.

  • <value: Text> The new value for the property.

Subcommand: nickname

Gives the current ticket a nickname. You don't have to include anything besides the nickname you want; the channel will be renamed with the correct format for you. You can also use spaces in the nickname, if you'd like.

Usage

  • /ticket nickname [name: Text]

Parameter Details:

  • [name: Text] The new nickname for the ticket. Spaces are allowed.

Subcommand: top

Creates a jump link to the top of the ticket, where the control panel is.

Usage

  • /ticket top

Subcommand: cleanup

Runs a cleanup routine to remove any bugged tickets and any bugged channels that are no longer attached to a valid ticket.

Usage

  • /ticket cleanup

Subcommand: history

Gets ticket history for the given Discord user. A type filter can be specified to only show tickets of a certain type. The history is limited to 25 results due to Discord's limitation on embeds-per-message.

Usage

  • /ticket history <user: Discord User> [type-filter: Ticket Type]

Parameter Details:

  • <user: Discord User> The user whose history to get.

  • [type-filter: Ticket Type] The type of ticket to filter by. Defaults to none, gathering tickets of any type.

Subcommand: history-by-closer

Gets history of tickets closed by a given moderator. A type filter can be specified to only show tickets of a certain type. The history is limited to 25 results due to Discord's limitation on embeds-per-message.

Usage

  • /ticket history-by-closer <closer: Discord User> [type-filter: Ticket Type]

Parameter Details:

  • <closer: Discord User> The moderator that closed the tickets.

  • [type-filter: Ticket Type] The type of ticket to filter by. Defaults to none, gathering tickets of any type.

Subcommand: history-by-recent

Gets history of recently closed tickets. The limit can be, at most, 25 due to a Discord limitation.

Usage

  • /ticket history-by-recent <limit: Integer>

Parameter Details:

  • <limit: Integer> The number of recent tickets to retrieve. Must be at least 1, but at most 25.

Subcommand: recall

Recall information about a previously closed ticket. This will include the original answers the user gave in the ticket creation modal. This is good for fact-checking user's claims about past tickets or otherwise figuring out what happened during an incident.

Usage

  • /ticket recall <ticket-id: Integer>

Parameter Details:

  • <ticket-id: Integer> The numeric ID of the ticket to recall.
