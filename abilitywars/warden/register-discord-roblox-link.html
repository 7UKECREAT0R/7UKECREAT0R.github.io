Register Discord-Roblox Link

Links a Roblox account to a Discord account permanently.

This can ONLY be run by a bot administrator as part of the Staff Linking process.

Usage

  • /staff-roblox-link <discord: Discord User> <roblox: Text>

Parameter Details:

  • <discord: Discord User> The Discord user to link.

  • [roblox: Text] The current username of the Roblox account to link to the given Discord account.
