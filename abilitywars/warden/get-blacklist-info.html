Get Blacklist Info

Gets information about a user's blacklist status from appealing/disputing. Blacklists can either be applied on a per-roblox-user basis, or on a per-discord-account basis.

Usages

  • /appeal-blacklist-info discord <user: Discord User>

  • /appeal-blacklist-info roblox <user: Player>

Subcommand: discord

Gets information about a Discord user's blacklist status from appealing/disputing.

Usage

  • /appeal-blacklist-info discord <user: Discord User>

Parameter Details:

  • <user: Discord User> The Discord user to get the blacklist status of.

Subcommand: roblox

Gets information about a Roblox user's blacklist status from appealing/disputing.

Usage

  • /appeal-blacklist-info roblox <user: Player>

Parameter Details:

  • <user: Player> The Roblox user to get the blacklist status of.
