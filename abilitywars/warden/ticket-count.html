Ticket Count

Counts the number of bans done by the given staff member for the current/last pay period.

Usage

  • /ticketcount <staff: Discord User> [lastweek: Boolean]

Parameter Details:

  • <staff: Discord User> The staff member to count the tickets for.

  • [lastweek: Boolean] If true, the count will be run for the last pay period instead of the current one. Defaults to False.
